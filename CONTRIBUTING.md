# Contributing to PyAutoLabs

The shared guide now lives at the organization level:
[Contributing to PyAutoLabs](https://github.com/PyAutoLabs/.github/blob/main/CONTRIBUTING.md).

It covers every PyAutoLabs repository. Start with the
[shared Discussions hub](https://github.com/orgs/PyAutoLabs/discussions)
for questions, ideas, and proposals; use the affected repository's issue
tracker for confirmed reproducible bugs and agreed implementation work.

For changes to PyAutoScientist itself, also read this repository's README
and AGENTS.md. PyAutoScientist and AI tools are optional for contributing
to the wider PyAutoLabs community.
